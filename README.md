># SQL Project Book Store Analysis — Data Analysis Queries

## Project Overview
This project contains SQL queries designed to explore, analyze, and derive insights from a dataset. It demonstrates the use of **SQL techniques** such as filtering, joins, aggregation, subqueries, and analytical functions.

The goal of this project is to strengthen SQL proficiency and apply it to solve real-world data problems efficiently.
